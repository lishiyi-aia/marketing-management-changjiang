# 李世怡 · 营销管理作品集

公开网站：https://lishiyi-aia.github.io/marketing-management-changjiang/

从原商务助理网站独立复制，保留 3D 人物、滚动镜头、履历时间轴及项目详情交互。内容依据 2026-10-13 最新营销管理简历更新，原网站和原仓库保持不变。

## 三个项目

| 项目 | 对应简历内容 | 工作闭环 |
| --- | --- | --- |
| AI 产品营销策划与渠道复盘 | 市场调研、营销策划、客户沟通、AI 看板、渠道推广 | 用户需求 → 方案与材料 → 渠道推广 → 数据复盘 → 预算、内容与 FAQ 调整 |
| AI 教育产品客户合作与项目推进 | 客户台账、合同核对、演示试点、项目进度、AI SOP | 需求确认 → 方案反馈 → 合同流转 → 试点推进 → 交接与流程复用 |
| ZUS Coffee 新品推广与渠道协同 | 新品调研、Instagram 内容、FamilyMart 渠道、周度复盘 | 调研卖点 → 主题与排期 → 内容执行 → 渠道传播 → 复盘与后续内容调整 |

首页简介及项目摘要保持简短，完整案例页展示流程、材料与方法。结果沿用简历口径：注册较前一周 +50%、首次专题创建率相对约 +15%、50 条 Instagram 内容、15+ 次复盘及账号粉丝增长 1.1w+。整体结果不归因于单条内容；看板与复盘示例中的模拟数据不作为真实业绩。

## 文件与部署

- `web/`：独立源文件，React + TypeScript + Vite。
- `docs/`：GitHub Pages 静态发布文件。
- GitHub Pages：`main` 分支 `/docs` 目录；相对资源路径支持独立仓库地址。

本地运行：进入 `web` 后安装依赖，运行 `npm run dev`。构建使用 `npm run build`，将 `web/dist` 内容同步到 `docs` 后发布。
